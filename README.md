# Metland Kairagi

Situs statis dengan enam halaman dan lima video transisi. Seluruh gambar, font, dan video untuk halaman sudah ada di folder `assets`.

## Buka di komputer

Ekstrak ZIP, lalu buka `index.html` dari folder hasil ekstrak dengan browser. Untuk meninjau melalui server HTTP lokal, jalankan `python -m http.server 8000` dari folder yang berisi `index.html`, lalu buka `http://localhost:8000/`.

Dari halaman pembuka, gulir ke bawah atau klik **Jelajahi Kawasan**. Video mengantar ke bab berikutnya, dan dapat dilewati.

## Pindahkan ke GitHub Pages

1. Unggah seluruh isi folder hasil ekstrak, termasuk `.nojekyll`, ke root repositori GitHub.
2. Di repositori, buka **Settings → Pages**. Gunakan **Deploy from a branch**, pilih branch yang berisi situs, lalu pilih folder **/(root)**.
3. Akses URL yang ditampilkan GitHub Pages. Tautan dan media menggunakan jalur relatif, sehingga situs bisa dibuka dari subfolder repositori.

Tautan Google Maps dan formulir kunjungan resmi Lorraine memerlukan internet. Lisensi font tersedia di folder `assets`.
